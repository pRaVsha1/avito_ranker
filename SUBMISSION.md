Репозиторий решения: https://github.com/pRaVsha1/avito_ranker

**Recall@50 на платформе — 0.882277.** В репозитории находятся выполненный Jupyter Notebook, прокомментированный Python-код, итоговый `answer.csv` и инструкции воспроизведения. В GitHub Release приложены данные, обученные модели, индексы и эмбеддинги. Команда `python reproduce.py --data-dir data --artifacts-dir artifacts --output answer_reproduced.csv` после подготовительной загрузки заново вычисляет ответ на CPU без внешних API и проверяет точное совпадение SHA-256 с отправленным файлом.

Метод объединяет BM25, символьный TF-IDF, поиск по историческим запросам, multilingual E5-small / E5-base и доменно дообученную E5-small. Для отбора 50 объявлений используется ансамбль CatBoost с поисковыми, текстовыми, категориальными и географическими признаками. Локация и фильтры учитываются мягко, без обязательного отсечения кандидатов.

Параметры выбраны по dev после разбиения по нормализованным текстам запросов с seed=42. Исторические признаки строятся без отложенных взаимодействий, позитивы не подмешиваются в кандидаты dev/test. Итоговые локальные Recall@50: dev 0.933194, контрольная test 0.925903. Эти оценки основаны на наблюдавшихся выборах пользователей, а не на полной разметке релевантности. В README и notebook приведены анализ ошибок поиска и отбора, ограничения проверки и список использованных open-source компонентов.
